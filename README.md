# Encuesta Bíblica de Ánimo 🙏📖

Aplicación web que presenta una encuesta de 10 preguntas y, según el puntaje total, devuelve un versículo bíblico motivador.

---

## 🌐 Tecnologías Usadas

- React + Vite (Frontend)
- Express.js (Backend)
- Docker y Docker Compose
- Helmet + CORS (seguridad)
- GitHub Actions (CI)
- Jest (Pruebas)
- Sin base de datos (versión simplificada)
